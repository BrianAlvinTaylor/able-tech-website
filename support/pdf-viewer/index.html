ABLE Tech PDF Viewer Support

Help with opening PDFs, light markup, page copies, saving and printing on Mac.

Contact support

For help with ABLE Tech PDF Viewer for macOS, contact ABLE Tech LLC.

Open and view a PDF

Choose Open in the blue toolbar or click Open a PDF in the center of the window. Select an unlocked PDF you can access on your Mac. Use the previous and next page controls to change pages. Fit Page shows the whole page; Fit Width fits it across the viewing area. Use the zoom controls or trackpad pinch to zoom. Mouse and trackpad scrolling pan within the page without changing pages.

Mark up a page while keeping the original

Choose Markup to create an editable copy of an original page at the end of the document. If the selected page is already an editable copy created by this app, you can continue working on it. The markup tools include text, highlights, freehand drawing, lines, arrows, rectangles and ovals. Choose a tool, then follow the instruction below the tools. Highlight requires selectable PDF text; it does not recognize text in scanned images.

Use Select to move or resize your markup, double-click a text note to edit it, and use Undo or Redo to revise changes. Hold the space bar while dragging to pan. Choose Done to return to viewing.

Arrange pages

Choose More Pages to show the thumbnail sidebar. Drag thumbnails to reorder pages, or use Earlier and Later for the selected page. Duplicate Page adds a copy at the end. Pages created for markup are labeled Edited in the sidebar.

Save a new PDF

Choose Save Copy, or press Command-S, and select a new filename. The app refuses to replace the source PDF or another existing file. The saved PDF includes the current page order, original pages and editable markup copies. Save before closing if you want to keep changes; work that has not been saved is not a separate file.

Print

Choose Print in the toolbar, or press Command-P, to open the macOS print dialog. Check the printer, page range and scaling before printing.

Opening or saving problems

If a PDF does not open, check that it is unlocked and readable, and that its disk or file provider is available. If saving fails, choose a new filename in a writable folder and check available storage. Exporting a large or complex PDF can take longer than editing a page. If a problem continues, contact support with the details below.

What to include when asking for help

  • The app name and version or build, if available.
  • Your Mac model and macOS version.
  • What you were doing, the document's approximate page count and file size, and any exact error message.
  • A screenshot with personal and confidential information removed.

Do not send passwords or confidential PDFs. Describe the problem first; support will ask if a nonconfidential sample is needed.
