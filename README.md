# ABLE Tech LLC website

Static, responsive corporate website prepared for GitHub Pages.

The product portfolio uses official App Store artwork and direct links for:

- [Grouped](https://apps.apple.com/us/app/grouped/id6760566346)
- [ColorAndPlay](https://apps.apple.com/us/app/colorandplay/id6757370248)
- [College4Less QuickCourse](https://apps.apple.com/us/app/college4less-quickcourse/id6809201605)
- [X Album](https://apps.apple.com/us/app/x-album/id6776722193)

## Preview

Open `index.html` directly or serve this directory with any static web server.

## Before publishing

- Confirm the final company domain and company-domain email address.
- Replace the temporary Contact page notice with verified contact information.
- Supply reviewed website Privacy and Terms content.
- Confirm all product descriptions and add final App Store/support links.
- Add the final `CNAME` file only after DNS and the GitHub Pages custom domain are ready.

## ABLE Studios

The series directory is in `studios/index.html`. `studios/one-little-line/index.html` has the public episode links and companion activity books.

Keep each book PDF, cover preview, and optional single-page PDF in `studios/one-little-line/books/`. Link the full book with **Open and print PDF** and **Download PDF** (the latter uses the HTML `download` attribute). Match the book card’s ID to its episode link. Add a new episode card when its YouTube video is public.
